# Demonstration papers

These two papers are the inputs for the method and comparison examples. They are included for private course review. The full 153-PDF collection remains a separate input, listed in `../corpus_manifest.json`.

- `DBLP_conf_icml_NyeHTS19.pdf`: Learning to Infer Program Sketches.
- `DBLP_journals_corr_abs-1906-04604.pdf`: Program Synthesis with a REPL.

The CLI uses this folder by default unless `data/papers/` contains PDFs or another corpus is configured. The historic results refer to the full collection. A live run on this smaller sample can select different passages and produce different wording.
