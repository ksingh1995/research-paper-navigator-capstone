# Demonstration papers

These two papers are the inputs for the method and comparison examples. PDFs remain local and are excluded from the updated repository. Obtain authorized copies from the publishers or authors and place them here if you want to use the CLI's sample-folder fallback. The full 153-PDF collection remains a separate input, listed in `../corpus_manifest.json`.

- `DBLP_conf_icml_NyeHTS19.pdf`: [Learning to Infer Program Sketches](https://proceedings.mlr.press/v97/nye19a.html).
- `DBLP_journals_corr_abs-1906-04604.pdf`: [Write, Execute, Assess: Program Synthesis with a REPL](https://arxiv.org/abs/1906.04604).

The CLI uses this folder by default unless `data/papers/` contains PDFs or another corpus is configured. The historic results refer to the full collection. A live run on this smaller sample can select different passages and produce different wording.
